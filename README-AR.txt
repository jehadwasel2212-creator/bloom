Bloom — الإصدار 1.0 | تطبيق PWA للآيفون
=========================================
لا يحتاج إلى Mac أو Xcode أو اشتراك Apple Developer.

1) تجربة على لابتوب HP
فكي ضغط الملفات، وافتحي index.html في Chrome أو Edge. ستظهر واجهة التطبيق. يمكنك تجربة الوظائف الأساسية. هذا الوضع ليس تثبيت PWA، ولا يُفعّل service worker. حفظ البيانات عند فتح ملف محلي يعتمد على المتصفح؛ لا تستخدميه للبيانات المهمة.

2) نشر مجاني باستخدام GitHub Pages (مرة واحدة)
- افتحي https://github.com/ وسجلي الدخول إلى حساب مجاني إن كان لديك حساب.
- اختاري New repository، واكتبي bloom-app واختر Public. يمكنك اختيار اسم مختلف لا يتضمن معلومات شخصية.
- بعد إنشاء المستودع، Add file → Upload files. ارفعي محتويات مجلد Bloom-PWA بما فيها assets (لا ترفعي ملف ZIP نفسه، ولا ملفات النسخ الاحتياطية أو معلومات خاصة). يجب أن يظهر index.html في جذر المستودع.
- Commit changes. ثم Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save.
- عند اكتمال النشر، يظهر رابط HTTPS في صفحة Pages. افتحيه على الآيفون.
- في Safari اختاري Share / مشاركة → Add to Home Screen / إضافة إلى الشاشة الرئيسية. فعّلي Open as Web App إن ظهر الخيار، ثم Add.
- افتحي Bloom من أيقونة الشاشة الرئيسية وهو متصل بالإنترنت أول مرة. انتظري حتى تُحمّل الملفات. افتحيه مرة أخرى واختبري وضع الطيران قبل الاعتماد على العمل دون اتصال.
- لا يحتاج اللابتوب إلى البقاء مفتوحًا بعد النشر. GitHub Pages العام مجاني؛ كود التطبيق عام، لكن السجلات الشخصية تبقى في تخزين المتصفح على الجهاز ولا تُرفع للخادم. لا ترفعي نسخ البيانات الشخصية للمستودع.

المراجع:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
https://support.apple.com/guide/iphone/turn-a-website-into-an-app-iphea86e5236/ios

3) حفظ البيانات
- يحفظ التطبيق التفضيلات، الجلسة النشطة، المجموعات، الملاحظات، السجلات، الألبومات والمكافآت محليًا في localStorage. عند العودة يمكن استكمال الجلسة من موقعها المحفوظ. عند الانتقال للخلفية، تتوقف الجلسة لحفظها.
- الإعدادات → تصدير نسخة احتياطية: احفظي ملف JSON في Files / iCloud Drive الخاص بك. الاستعادة من نفس الشاشة تستبدل البيانات المحلية بعد تأكيدك.
- لا توجد مزامنة سحابية تلقائية. استخدام Safari والتطبيق المثبت قد يملك تخزينًا منفصلًا. استخدمي تصدير/استيراد لنقل البيانات. مسح بيانات المواقع أو إزالة التطبيق أو قيود التخزين قد تمسح البيانات. احتفظي بنسخة احتياطية.
- لا تسجيل دخول داخل Bloom ولا إعلانات أو تتبع. الاستضافة العامة تعرض ملفات التطبيق فقط.

4) ما تم تنفيذه
- 6 ثيمات مع معاينة، وضع فاتح وداكن وتلقائي، واجهة عربية وإنجليزية، اتجاه RTL/LTR.
- جدول الخميس والسبت والاثنين: قابل لتعديل ترتيب الحركات، مجموعاتها، تكراراتها، وقت الراحة، وإضافة/إزالة بديل.
- 19 دليل حركة، شرح إنجليزي كامل وخطوات عربية، أسماء باللغتين، رسوم توضيحية متحركة مبسطة. ليست فيديوهات تدريب احترافية.
- جلسة محفوظة، مؤقت راحة، متابعة/إيقاف/تخطي/استبدال، تسجيل مجموعة، ملاحظات، إنهاء مبكر بدون عقوبة.
- 12 بطاقة إلهام مصورة برسوم أصلية، مفضلة وألبومات، بيانات محلية.
- 3 رفيقات اختيارية، إكسسوارات وزينة، نقاط افتراضية متساوية للحركة أو الراحة أو تسجيل المشاعر، هدية أسبوعية ثابتة بلا شروط. لا شراء حقيقي أو مكافآت عشوائية.
- تقارير أسبوعية وشهرية للسجل والنوم والطاقة والتعافي والمرونة، ملاحظات، تاريخ احتفال اختياري مستقل عن أي هدف جسدي.
- تنبيهات داخل التطبيق عند فتحه وتصدير تقويم ICS. لا إشعارات خلفية تلقائية؛ يلزم استيراد التقويم للتذكيرات خارج التطبيق، ويعتمد ذلك على تطبيق التقويم.
- الإرشاد الصوتي وإبقاء الشاشة مضاءة يعتمدان على دعم Safari. تقليل الحركة متاح. بعض إمكانات iOS الأصلية مثل الاهتزازات ليست متاحة بصورة موحدة.

5) الاختبار والحدود
تم فحص JavaScript باستخدام Node، واختبار منطق الحالة والرسم النصي للشاشات في بيئة DOM بديلة: الثيم، سجل التمرين، الإيقاف والاستكمال، الملاحظات، المكافآت، المفضلة والتحقق من صيغة النسخة الاحتياطية. اختبار Chromium الفعلي لم ينجح لأن سياسة المتصفح في بيئة الإنشاء حجبت الرابط المحلي؛ لم يُختبر Safari أو التثبيت دون اتصال على آيفون حقيقي. المشروع جاهز للنشر والاختبار، وليس نسخة مثبتة أو مضمونة على كل إصدار iOS.

تم تصميم Bloom لتشجيع الحركة المريحة والراحة، لا تغيير شكل الجسم أو الضغط لاتباع جدول. محتوى الحوض تثقيفي ليس تشخيصًا أو علاجًا. عند ألم مستمر، استشيري مختصًا.
